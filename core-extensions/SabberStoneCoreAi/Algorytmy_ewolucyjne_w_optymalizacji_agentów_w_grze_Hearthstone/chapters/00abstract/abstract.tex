\section*{Streszczenie}

Praca dotyczy optymalizacji agentów parametrycznych dla gry Hearthstone z wykorzystaniem algorytmów ewolucyjnych. Punktem wyjścia był agent bazowy oparty na funkcji oceny stanu gry. Celem badań było sprawdzenie, czy zaproponowane modyfikacje reprezentacji i procesu decyzyjnego poprawiają skuteczność turniejową oraz czy adaptacyjny algorytm SHADE prowadzi do lepszych wyników niż klasyczna koewolucja.

W ramach pracy zaprojektowano pięć wariantów agenta: rozszerzenie do 28 parametrów, wariant 28 z normalizacją, wariant 63-parametrowy, wariant 63 z płynnym przejściem faz oraz wariant 21 głębokościowy. Ocenę przeprowadzono w trzech fazach: selekcji reprezentantów, turnieju głównym wszystkich wariantów oraz walidacji zewnętrznej względem agenta Sebastiana Millera (\textit{2-Step Lookahead}), zwycięzcy edycji 2020 konkursu Hearthstone AI Competition.

Najlepszy wynik w turnieju głównym uzyskał wariant 21 głębokościowy. Analizy zbieżności i profili wag potwierdziły, że kluczowy efekt jakościowy wynika przede wszystkim ze zmiany sposobu podejmowania decyzji, a nie wyłącznie ze zwiększania liczby współczynników funkcji oceny. W strojeniu parametrów SHADE najbardziej stabilne wyniki osiągnięto dla populacji o rozmiarze 15. W walidacji zewnętrznej wariant 21 głębokościowy osiągnął wyraźnie lepszy wynik przeciwko agentowi Sebastiana Millera niż agent bazowy.

Uzyskane rezultaty pokazują, że połączenie adaptacyjnej optymalizacji ewolucyjnej z częścią planowania głębokościowego jest skutecznym kierunkiem rozwoju agentów dla gier karcianych o niepełnej informacji.

\textbf{Słowa kluczowe:} Hearthstone, sztuczna inteligencja w grach, algorytmy ewolucyjne, SHADE, optymalizacja agentów.

\section*{Abstract}

This thesis focuses on optimizing parametric agents for Hearthstone using evolutionary algorithms. The starting point is a baseline agent built on a state of the game evaluation function. The study investigates whether the proposed modifications to the agent's representation and decision process improve tournament performance and whether the adaptive SHADE algorithm leads to better results than classical coevolution.

Five agent variants were designed and evaluated: a 28-parameter extension, a normalized 28-parameter variant, a 63-parameter phased variant, a smooth 63-parameter phased variant, and a 21-parameter depth-based lookahead variant. Evaluation is organized into three stages: representative selection, a main tournament among all variants, and an external validation against Sebastian Miller's \textit{2-Step Lookahead} agent, the winner of the 2020 Hearthstone AI Competition.

The 21-parameter depth-based variant achieves the best result in the main tournament. Convergence and weight-profile analyzes confirm that the main quality gain comes from changing how decisions are made, not just from increasing the number of evaluation features. In SHADE parameter tuning, the most stable results are obtained for a population size of 15. In external validation, the depth-based variant performs clearly better against Sebastian Miller's agent than the baseline.

The results show that combining adaptive evolutionary optimization with a depth-based planning component is an effective direction for developing agents in imperfect-information collectible card games.

\textbf{Keywords:} Hearthstone, game artificial intelligence, evolutionary algorithms, SHADE, agent optimization.
